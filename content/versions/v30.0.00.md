Marking a milestone release and 15 years of development, Gibbon v30 includes two new core modules, both designed to improve school communication and workflow: Calendar and Student Alerts. This release also includes improvements to the Timetable UI, a new Pastoral heading in the main menu, a photo history to store user images from previous years, tools for admins to troubleshoot user accounts, and a host of other improvements.

Gibbon v30.0.03 contains essential updates for all current installations. Our thanks to Peter Wilfahrt (p-w), Seydina Mouhamed Rassoul Sow (Mouha7), Ari Balachsan and Sabuhi Mammadov for their help to analyze and identify security improvements for Gibbon. Information about our security policy can be found on [our GitHub repository](https://github.com/GibbonEdu/core/security/policy).

## Development Update

**Please note, the next release (v30.0.04) will require a minimum of PHP 8.2**. We would generally avoid a PHP version increase in a patch release, however in order to update all of our PHP libraries to the latest version, we can no longer support end-of-life PHP versions. 

If you have not already updated your PHP version to 8.2+ since Oct 21, 2026, please do so immediately. Note that this is not a vulnerability in Gibbon itself, but in the underlying programming language, which is a global vulnerability affecting upwards to 70% of the internet. See [our forum post](https://ask.gibbonedu.org/t/important-security-notice-php-vulnerability-action-required-for-all-school-administrators/15608) for more information.

In light of the increased cybersecurity awareness, we have paused development of new features for Gibbon and will be focusing upcoming releases on security improvements. A top priority of this focus will be to build an auto-update feature into Gibbon so that we can deploy patches to our community faster and seamlessly. As such, work on Gibbon v31 has been paused while we focus our efforts on this essential security work.

### Translation

Gibbon v30 also brings three new languages to production: Catalan, Japanese and Portuguese. Our continued thanks go out to our hard working Gibbon translators: powered by their efforts, Gibbon is now available in 29 languages. If you would like to volunteer to translate Gibbon into your language, please email [support@gibbonedu.org](mailto:support@gibbonedu.org).

### Important Notes for v30.0.03

- Gibbon v30.0.03 contains important security updates, if you are running an earlier version, it is highly recommended to update. See the [release notes](https://github.com/GibbonEdu/core/releases/tag/v30.0.03) for more information.
- Gibbon requires a minimum PHP version of 8.0 and MySQL version of 8.0. Please check to ensure your server supports this requirement. Gibbon v30 supports up to PHP 8.3, which is currently the highest recommended version.
- Always backup your files and database before upgrading.
- See the [Updating Gibbon](https://docs.gibbonedu.org/administration/updating-gibbon) guide for detailed steps.
